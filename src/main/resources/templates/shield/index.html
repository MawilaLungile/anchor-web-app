Protect your devices

A website can't filter your device by itself, so Anchor gives you two proven ways to block adult content everywhere. Use either, or both.

1 · Family DNS (recommended, works on every device)

Cloudflare for Families blocks adult content and malware for free at the network level.

  • Android: Settings → Network & internet → Private DNS → set hostname to family.cloudflare-dns.com
  • Windows: Settings → Network → your connection → DNS server assignment → Manual → 1.1.1.3 and 1.0.0.3
  • iPhone / iPad: Settings → Wi-Fi → (i) → Configure DNS → Manual → 1.1.1.3 and 1.0.0.3
  • Whole home: set the same two addresses as the DNS servers in your router
